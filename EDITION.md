## Translation decisions

Instructions, reference methods, examples, interface metadata, historical evaluation descriptions, and the interactive HTML template are in English. The two long writing libraries preserve their six and fourteen substantive method chapters with edited English phrasing and tables. English is the default report language unless the task specifies another language. A user's protected source text remains in its original language when the task requires that.

Chinese-dialogue and Chinese-to-English localization workflows retain their language boundaries. Original-English writers can use the general development methods and English polish; translation fidelity is unverified when no source-language draft is supplied. Territory and variety of English are project choices, not a universal US default.

Historical genre heuristics, episode/time examples, character counts, and production-risk tables are labeled as contextual references. Chinese character counts have not been converted into English word targets. The traditional first-paywall “card” concept is explained as an opening delivery block or story phase in prose, while existing template data keys remain compatible.

The original brand's copyright notice is rendered in English as **Emma Short Drama**, referring to the same copyright holder. The MIT permission and warranty language is unchanged.

## Source provenance and archives

Historical source hashes, candidate IDs, and source-document counts are retained as historical metadata. They are not hashes of the English files or proof of a new test run. Source documents not included in the public package remain unbundled. Source URLs are provenance records, not a claim that those pages were rechecked for this edition.

The original's three historical Chinese ZIPs are omitted from this English working tree to avoid distributing an old-language package as an English install. The GitHub repository ZIP contains the current English files. Git history retains the source history as provenance; earlier source commits naturally contain the original Chinese edition.

The public source's external `humanizer-zh` dependency is identified explicitly. `drama-truesource` is optional where equivalent direct source checks are specified. Neither external package is silently represented as bundled.
